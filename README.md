# 🍈 Melon Archive

一个用于Melonbooks商品详情页的油猴脚本。它可以生成格式统一的同人志标题、保存私人购买记录，并按需归档商品图片。

## ✨ 功能

脚本会用拼接完成的完整标题替换商品详情页原有的主标题文本，同时保持页面原有的标题样式，并在标题下方及商品信息右侧提供以下操作：

- **⚙️ 设置窗口**：通过Tampermonkey菜单调整页面功能和拼接标题格式，设置会持久保存。
- **📋复制信息**：生成同人志标题并复制到剪贴板。
- **📥复制并下载封面**：复制标题，同时下载商品封面。
- **🛍️私人购买记录**：在同人商品页保存商品资料、实际购买日期、入库时间、购买数量、备注和自定义标签。
- **🖼️图片归档**：可以把封面缩略图或完整商品图片保存到浏览器数据库，也可以写入用户授权的本地目录。
- **价格快捷复制**：点击商品主价格即可复制去除逗号和货币符号后的纯数字金额，例如`1,100`会复制为`1100`。
- **展会／社团／作者／标题／分类**：在商品信息右侧纵向显示五个字段按钮；按钮文字过长时会截断显示，但复制内容保持完整。没有相应信息的按钮会显示“无作者信息”等提示，使用不同颜色并停用复制功能。
- **表示【】内容**：控制是否保留商品主标题中的`【…】`内容；默认显示，取消勾选后隐藏，并且仅在原始标题含有`【…】`时提供该选项。
- **発行日显示**：读取商品详情中的発行日，统一为`YYYY年MM月DD日`格式并显示在発売日上方。
- **页面操作布局**：将“お気に入りサークルに追加”和“ほしいものリストに追加”移动到“配送方法”区域上方，方便集中操作。

生成的标题采用以下格式：

```text
(イベント) [サークル (作家)] タイトル (ジャンル)
```

缺少活动、社团、作者或分类信息时，脚本会根据页面中实际取得的内容组合标题。当页面有社团名但没有作者名时，会保留空的`()`，方便之后手动补充作者。

## ⚙️ 设置

在受支持的商品页面中打开Tampermonkey菜单，点击**⚙️ Melon Archive 设置**即可打开设置窗口。可调整以下项目：

- 是否默认表示商品标题中的`【…】`内容
- 是否启用价格点击复制
- 是否在発売日上方显示発行日
- 是否移动收藏与愿望单按钮
- 是否显示五个字段复制按钮
- 拼接标题是否包含展会、社团、作者和分类
- 是否启用私人购买记录
- 图片使用浏览器数据库或本地目录后端
- 图片只保存缩略图、完整封面，或封面／预览图／特典图

设置窗口还会显示购买记录数量及浏览器图片占用空间，并提供持久存储申请、购买记录JSON导出和合并导入功能。

商品标题本身始终保留。点击**保存并刷新**后，设置会保存到Tampermonkey的脚本存储中，并通过刷新当前页面生效；点击**恢复默认**可将窗口中的所有选项恢复为初始状态。

## 🌐 支持的网站

- Melonbooks商品详情页：`/detail/detail.php`与`/products/detail.php`

页面结构由网站运营方维护；如果网站改版，部分信息提取或封面下载功能可能需要相应更新。

## 📥 安装

1. 安装[Tampermonkey](https://www.tampermonkey.net/)等用户脚本管理器。
2. 打开[melon-archive.user.js](https://raw.githubusercontent.com/uyuni-saline/melon-archive/main/melon-archive.user.js)。
3. 在用户脚本管理器显示的安装页面中确认安装。

脚本管理器会通过脚本内的更新地址检查`main`分支上的新版本。

## 🛠️ 使用方法

1. 打开支持网站中的商品详情页。
2. 确认页面原有的商品主标题已替换为脚本生成的完整标题。
3. 如需调整功能或标题格式，从Tampermonkey菜单打开**⚙️ Melon Archive 设置**并保存。
4. 根据需要复制完整标题、下载封面，或使用商品信息右侧的字段按钮单独复制展会、社团、作者、标题或分类；灰色弱化的“无…信息”按钮无法点击。
5. 如果页面显示**表示【】内容**复选框，它会采用设置中的默认状态；切换后，页面主标题和“标题”字段按钮会立即同步更新。
6. 启用价格复制时，点击商品主价格即可复制纯数字金额；也可以聚焦价格后按Enter或空格键复制。
7. 点击**🛍️标记已购买**填写购买信息。实际购买日期可以留空，也可以填写`YYYY`、`YYYY-MM`或`YYYY-MM-DD`；脚本会另外自动保存入库时间。
8. 重复购买同一商品时再次打开购买记录并添加批次，页面按钮会显示`✅已购买 ×数量`。
9. 复制和下载按钮在操作后只显示简短状态，不会追加完整的拼接标题；字段按钮则会在短暂显示复制状态后恢复字段内容。

下载文件的扩展名会根据封面图片类型自动选择。文件名中不适合Windows、macOS或Linux使用的字符会转换为对应的全角字符。

## 🗃️ 购买记录与图片

购买记录初版仅在页面分类包含“同人”的商品详情页显示。保存内容包括商品ID、标准链接、原始标题、完整拼接标题、标题组成字段、页面分类、官方Tag、商品详情、社团评论、工作人员推荐、图片信息及购买批次。页面缺少的可选字段会按空值处理，不会生成虚假内容。

### 🌐 浏览器数据库

默认将压缩后的封面缩略图作为Blob保存到IndexedDB，并保留所有商品图片的原始地址。也可以在设置中改为保存完整封面或全部商品图片。浏览器数据可能因清除站点数据、重建浏览器配置或卸载相关扩展而丢失，因此请定期导出购买记录。

### 📁 本地目录

Chrome和Edge用户可以在设置中选择一个专用目录。脚本会把图片写入`images`目录，并把每件商品的JSON资料写入`products`目录：

```text
MelonArchive/
├── images/
│   └── <SHA-256>.<扩展名>
└── products/
    └── <商品ID>.json
```

图片以内容哈希命名，相同图片和NowPrinting占位图只保存一份。浏览器可能在之后再次要求目录权限。请只授权专用的MelonArchive目录，不要授权整个用户目录或云盘根目录。如果将该专用目录放在Nextcloud等桌面同步目录中，云同步由对应客户端完成。

### 💾 备份与迁移

设置窗口中的**导出记录JSON**只导出商品资料和购买记录，不包含浏览器数据库中的图片Blob；**合并导入JSON**会按商品ID合并记录，并保留不同的购买批次。使用本地目录后端时，图片文件和每件商品的JSON资料已经位于所选目录中，应与购买记录JSON一同备份。

## 🔐 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `GM_addStyle` | 显示操作按钮及其状态 |
| `GM_registerMenuCommand` | 在Tampermonkey菜单中提供设置入口 |
| `GM_getValue`／`GM_setValue`／`GM_deleteValue` | 读取、保存或恢复脚本设置 |
| `GM_setClipboard` | 将生成的标题复制到剪贴板 |
| `GM_notification` | 在信息提取或下载失败时显示提示 |
| `GM_xmlhttpRequest` | 读取商品页中的封面、预览图及特典图 |
| `@connect *` | 允许从商店实际使用的不同图片CDN下载商品图片 |

脚本不会主动上传商品信息、购买记录、图片或剪贴板内容。购买记录保存在浏览器数据库中；选择本地目录后，脚本只能访问用户明确授权的目录。下载请求的目标仅取自当前商品页面中的图片地址。

## ❓ 常见问题

### 🧩 页面中没有出现按钮

请确认当前页面是受支持的商品详情页，然后刷新页面。如果网站刚刚调整过页面设计，脚本使用的页面元素选择器可能需要更新。

### 📝 标题中的部分信息为空

脚本只能读取商品页面实际提供的活动、社团、作者及分类信息。缺少的内容可以在复制后手动补充。

### 🖼️ 封面下载失败

请先确认封面已经在页面中正常显示，并检查Tampermonkey是否允许脚本下载文件及访问图片所在域名。

### 📁 无法选择本地图片目录

本地目录后端依赖File System Access API，请使用最新版Chrome或Edge。Firefox等不支持该接口的浏览器可以继续使用浏览器数据库后端。

### 💾 导入JSON后没有恢复图片

初版JSON备份只包含商品资料和购买记录，不包含图片Blob。图片仍可通过记录中保存的原始地址重新取得；使用本地目录后端时，请另外备份所选目录。
