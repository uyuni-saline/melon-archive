# 🍈 Melon Archive

一个用于Melonbooks商品详情页的油猴脚本。它可以生成格式统一的同人志标题，并将商品封面以该标题作为文件名保存到本地。

## ✨ 功能

脚本会用拼接完成的完整标题替换商品详情页原有的主标题文本，同时保持页面原有的标题样式，并在标题下方及商品信息右侧提供以下操作：

- **📋复制信息**：生成同人志标题并复制到剪贴板。
- **📥复制并下载封面**：复制标题，同时下载商品封面。
- **固定主按钮**：两个主按钮在操作状态变化时保持相同大小，避免页面布局跳动。
- **展会／社团／作者／标题／分类**：在商品信息右侧纵向显示五个字段按钮；按钮文字过长时会截断显示，但复制内容保持完整。没有相应信息的按钮会显示“无作者信息”等提示，使用不同颜色并停用复制功能。
- **表示【】内容**：控制是否保留商品主标题中的`【…】`内容；默认显示，取消勾选后隐藏，并且仅在原始标题含有`【…】`时提供该选项。
- **発行日显示**：读取商品详情中的発行日，统一为`YYYY年MM月DD日`格式并显示在発売日上方。
- **页面操作布局**：将“お気に入りサークルに追加”和“ほしいものリストに追加”移动到“配送方法”区域上方，方便集中操作。

生成的标题采用以下格式：

```text
(イベント) [サークル (作家)] タイトル (ジャンル)
```

缺少活动、社团、作者或分类信息时，脚本会根据页面中实际取得的内容组合标题。当页面有社团名但没有作者名时，会保留空的`()`，方便之后手动补充作者。

## 🌐 支持的网站

- Melonbooks商品详情页：`/detail/detail.php`与`/products/detail.php`

页面结构由网站运营方维护；如果网站改版，部分信息提取或封面下载功能可能需要相应更新。

## 📥 安装

1. 安装[Tampermonkey](https://www.tampermonkey.net/)等用户脚本管理器。
2. 打开[melon-archive.user.js](https://raw.githubusercontent.com/uyuni-saline/melon-archive/main/melon-archive.user.js)。
3. 在用户脚本管理器显示的安装页面中确认安装。

脚本管理器会通过脚本内的更新地址检查`main`分支上的新版本。

## 🛠️ 使用方法

1. 打开支持网站中的商品详情页。
2. 确认页面原有的商品主标题已替换为脚本生成的完整标题。
3. 根据需要复制完整标题、下载封面，或使用商品信息右侧的字段按钮单独复制展会、社团、作者、标题或分类；灰色弱化的“无…信息”按钮无法点击。
4. 如果页面显示**表示【】内容**复选框，它会默认保持勾选；取消勾选后，页面主标题和“标题”字段按钮会立即隐藏原始标题中的`【…】`内容。
5. 两个主按钮在操作后只显示简短状态，不会追加完整的拼接标题；字段按钮则会在短暂显示复制状态后恢复字段内容。

下载文件的扩展名会根据封面图片类型自动选择。文件名中不适合Windows、macOS或Linux使用的字符会转换为对应的全角字符。

## 🔐 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `GM_addStyle` | 显示操作按钮及其状态 |
| `GM_setClipboard` | 将生成的标题复制到剪贴板 |
| `GM_notification` | 在信息提取或下载失败时显示提示 |
| `GM_xmlhttpRequest` | 读取商品页中的封面图片并保存为文件 |
| `@connect *` | 允许从商店实际使用的不同图片CDN下载封面 |

脚本不会上传商品信息或剪贴板内容。下载请求的目标仅取自当前商品页面中显示的封面图片地址。

## ❓ 常见问题

### 🧩 页面中没有出现按钮

请确认当前页面是受支持的商品详情页，然后刷新页面。如果网站刚刚调整过页面设计，脚本使用的页面元素选择器可能需要更新。

### 📝 标题中的部分信息为空

脚本只能读取商品页面实际提供的活动、社团、作者及分类信息。缺少的内容可以在复制后手动补充。

### 🖼️ 封面下载失败

请先确认封面已经在页面中正常显示，并检查Tampermonkey是否允许脚本下载文件及访问图片所在域名。
